# 全局错误码 v1.0.0

所有失败响应 HTTP 状态码为 4xx/5xx，响应体统一为：

```json
{ "code": 2001, "message": "当前不在点餐时间（14:00-18:00）" }
```

成功响应直接返回业务数据（HTTP 2xx），不包裹 code/message。

| code | HTTP | 含义 | 触发场景 |
|---|---|---|---|
| 1001 | 401 | 登录失败 | 登录名不存在或密码错误；修改密码时旧密码错误 |
| 1002 | 401 | 凭证无效 | token 缺失/伪造/过期/`pwdVer` 不匹配 |
| 1003 | 403 | 权限不足 | 访问 ADMIN 接口但角色为 USER |
| 1004 | 400 | 参数校验失败 | 字段缺失/格式非法（message 指明具体字段） |
| 1005 | 409 | 登录名已存在 | 管理员创建用户时 loginName 重复 |
| 2001 | 409 | 非点餐窗口 | 窗口外新增/修改/取消点餐（管理员不受限） |
| 2002 | 404 | 记录不存在 | 取消点餐时当天无记录 |
| 3001 | 500 | 数据文件读写失败 | 文件 IO 异常（message 不暴露路径细节） |
| 404 | 404 | 接口不存在 | 请求的 API 路径未匹配（系统级，D-007） |
| 5000 | 500 | 服务器内部错误 | 未捕获异常（系统级，D-007） |
