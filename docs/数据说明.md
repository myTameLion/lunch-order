# 数据说明

无数据库。全部业务数据以 JSON 文件落盘（契约：`shared/contracts/data-file.md`）。

## 目录布局

```
$LUNCH_DATA_DIR/            # 环境变量，默认 <启动目录>/data
├── users.json              # 全部用户账号（BCrypt 密码哈希 + pwdVer 密码版本号）
├── config.json             # 点餐窗口/提醒时间配置
└── orders/
    ├── 2026-09-05.json     # 每天一个点餐记录文件
    └── ...
```

## 关键语义

- `users.json` 缺失时，服务端启动自动**种子初始化**：`admin/admin123`（ADMIN，姓名"管理员"）+ 5 个演示账号（zhangsan 张三 / lisi 李四 / wangwu 王五 / zhaoliu 赵六 / sunqi 孙七，密码均 `123456`）。
- 每人每天最多一条点餐记录；重复提交=修改；窗口外（默认 [14:00, 18:00] 闭区间，Asia/Shanghai）不可新增/修改/取消（管理员不受限）。
- 写入均为原子写（临时文件 + ATOMIC_MOVE）+ 进程内写锁，不会因并发产生半截文件。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `LUNCH_DATA_DIR` | `./data` | 数据根目录 |
| `LUNCH_JWT_SECRET` | 内置开发值（启动打 warn） | JWT 签名密钥，生产必须设置 |
| `LUNCH_WINDOW_START` / `LUNCH_WINDOW_END` | 14:00 / 18:00 | 覆盖 config.json 的点餐窗口 |

## 备份与恢复

- **备份**：直接拷贝 `$LUNCH_DATA_DIR` 整个目录即可（运行中拷贝也安全，原子写保证单文件完整）。
- **恢复**：停服后把备份目录放回原位再启动。
- **重置**：`scripts/reset-data.sh [目录]`（删除后重启即重新种子初始化）。
